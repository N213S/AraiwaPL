1. LEXICAL GRAMMAR AND TOKENS
--------------------------------------------------------------------------------

[Comments]
- Single-line:
  รูปแบบ: อันนี้ไม่ใช้: <ข้อความ>
  พฤติกรรม: ข้ามข้อความทั้งหมดตั้งแต่หลังเครื่องหมาย : ไปจนสุดบรรทัด
- Multi-line:
  รูปแบบ: อันนี้ไม่ใช้="<ข้อความหลายบรรทัด>"=
  พฤติกรรม: ข้ามข้อความทั้งหมดที่อยู่ระหว่าง =" และ "=
- Trap Rule (ห้ามใช้ //):
  หากพบ Token "//" ในโค้ด ให้ระบบหยุดทำงานทันทีและส่ง Error:
  SyntaxError: ใส่ขีดสองอันมาทำไมวะ จำไม่ได้เหรอว่าต้องพิมพ์ว่า อันนี้ไม่ใช้:

[Delimiters]
- วงเล็บเปิด "(" แทนด้วย: /
- วงเล็บปิด ")" แทนด้วย: \
- ปีกกาเปิด "{" แทนด้วย: อยู่ในนี้
- ปีกกาปิด "}" แทนด้วย: เหรอวะ
- Argument Pipeline: ใช้สัญลักษณ์ | ปิดหัวท้าย เช่น |ตัวแปร1, ตัวแปร2|

[Statement Terminator and Linter Rule]
- ทุกคำสั่งต้องลงท้ายด้วยคำว่า "นะ"
- กฎการตรวจจับ Spacebar (Linter Warning):
  - นับจำนวนช่องว่าง (Space) ก่อนหน้าคำว่า "นะ"
  - หากเว้นวรรค 0 ถึง 10 ช่อง: ผ่านตามปกติ
  - หากเว้นวรรคมากกว่า 10 ช่อง: ให้โปรแกรมรันต่อได้ตามปกติ แต่พิมพ์ข้อความเตือนออก stderr:
    [คำเตือน]: เว้นวรรคหาพ่อมึงเหรอ เคาะ Spacebar เยอะขนาดนี้แป้นพิมพ์มึงค้างเหรอวะ? (แต่ช่างแม่ง รันต่อให้ก็ได้)
- หากลืมใส่ "นะ" ท้ายคำสั่ง:
  SyntaxError: คำสั่งไม่มีหางเสียง กรุณาลงท้ายด้วย นะ

--------------------------------------------------------------------------------
2. KEYWORDS AND IDENTIFIERS
--------------------------------------------------------------------------------

[จุดเริ่มต้นโปรแกรม]
- yo เริ่มละนะ : ใช้เป็น Entry Point ฟังก์ชันหลัก

[การนำเข้าโมดูล]
- นำเข้าจากแดนไกล : คำสั่ง Import
- ครับ / ค่ะ : คำลงท้ายคำสั่ง Import บังคับต้องเลือกใช้อย่างใดอย่างหนึ่ง

[ชนิดข้อมูล (Types)]
- ตัวเลข : ข้อมูลประเภท Number (รองรับทั้ง Integer และ Float)
- ข้อความ : ข้อมูลประเภท String (เขียนอยู่ในเครื่องหมายคำพูด "...")
- เรื่องโกหก : ข้อมูลประเภท Boolean

[ค่าคงที่ของ Boolean]
- จริง : ค่า True
- ตอแหล : ค่า False

[คำสั่งควบคุมทิศทาง (Control Flow)]
- ถ้า : คำสั่ง If
- ช่างแม่ง : คำสั่ง Else
- วนแม่งเข้าไป : คำสั่ง While loop
- เอาตั้งแต่ : คำสั่ง For range loop
- ไปจนถึง : ตัวคั่นช่วงตัวเลขใน For loop
- พอเหอะ : คำสั่ง Break (หยุดลูปทันที)
- ช่างมันรอบนี้ : คำสั่ง Continue (ข้ามไปรอบถัดไป)

[คำสั่ง Input/Output และการจบงาน]
- ตะโกน : แสดงผลออกหน้าจอ (print)
- พอละเหนื่อย : คืนค่าและออกจากฟังก์ชัน (return)

--------------------------------------------------------------------------------
3. OPERATORS
--------------------------------------------------------------------------------

[เครื่องหมายคำนวณและเชื่อมคำ]
- + : เครื่องหมายบวกตัวเลข หรือบวก Boolean
- - : เครื่องหมายลบ
- * : เครื่องหมายคูณ
- / : หากไม่ได้ทำหน้าที่เปิดวงเล็บ ให้ถือเป็นเครื่องหมายหาร
- ฿ : เครื่องหมายต่อข้อความ (String Concatenation) เท่านั้น

[เครื่องหมายเปรียบเทียบ]
- มากกว่า : >
- น้อยกว่า : <
- เท่ากับ : ==
- ไม่เท่ากับ : !=
- มากกว่าหรือเท่ากับ : >=
- น้อยกว่าหรือเท่ากับ : <=

4. RUNTIME EXCEPTIONS AND CHAOS RULES
--------------------------------------------------------------------------------

[กฎการบวกข้ามประเภท ด้วยเครื่องหมาย +]
1. ข้อความ + ตัวเลข หรือ ตัวเลข + ข้อความ:
   ห้ามแปลงค่าอัตโนมัติ และให้หยุดการทำงานทันทีด้วยข้อความ:
   RuntimeError: ลองไปถามพ่อมึง
   (หากต้องการนำข้อความกับตัวเลขมาต่อกัน บังคับต้องใช้เครื่องหมาย ฿ เท่านั้น)
2. เรื่องโกหก + ตัวเลข:
   คำนวณได้ตามปกติ โดย "จริง" มีค่าเท่ากับ 1 และ "ตอแหล" มีค่าเท่ากับ 0
3. เรื่องโกหก + ข้อความ:
   แปลงค่าเป็นสตริง "จริง" หรือ "ตอแหล" แล้วนำมาต่อกันอัตโนมัติ

[กฎตัวเลขต้องห้าม]
เมื่อมีการกำหนดค่าตัวแปร, การคำนวณได้ผลลัพธ์, หรือค่าคงที่ในโค้ด:
1. ตัวเลขมีค่าเท่ากับ 67 หรือ 67.0:
   หยุดทำงานทันทีด้วยข้อความ:
   RuntimeError: บ่ ไม่ขำ gen alpha หรือไง
2. ตัวเลขมีค่ามากกว่า 6967:
   หยุดทำงานทันทีด้วยข้อความ:
   RuntimeError: อะไรวะ จำไม่ได้
   (ข้อยกเว้น: หากต้องการเก็บตัวเลขที่เกินกว่านี้ ต้องเก็บเป็น "ข้อความ" เท่านั้น)

[กฎศุลกากรแดนไกล (Import Rule)]
- คำสั่ง "นำเข้าจากแดนไกล" ต้องลงท้ายด้วย "ครับ" หรือ "ค่ะ" เท่านั้น
- ห้ามใช้คำว่า "นะ" และห้ามเว้นว่าง
- หากผิดกฎ ให้หยุดทำงานทันทีด้วยข้อความ:
  RuntimeError: ศุลกากรปฏิเสธพัสดุ พูดจาห้วนเกินไป กรุณาลงท้ายด้วย ครับ หรือ ค่ะ ให้เรียบร้อย

[กฎลูปทำงานหนักเกินไป (Loop Trap)]
- ตัว Interpreter ต้องนับรอบการทำงานของลูปทุกครั้ง
- หากลูปใดลูปหนึ่ง (ทั้ง วนแม่งเข้าไป หรือ เอาตั้งแต่) ทำงานวนซ้ำเกิน 6967 รอบ:
  ให้ตัดจบการทำงานทันทีด้วยข้อความ:
  FatalError: วนเหี้ยไรเกิน 6967 รอบ อะไรวะ จำไม่ได้ เหนื่อยโว้ย!

5. GRAMMAR STRUCTURE
--------------------------------------------------------------------------------

โครงสร้างโปรแกรม:
  <โปรแกรม> ::= <คำสั่งนำเข้า>* <จุดเริ่มโปรแกรม>

คำสั่งนำเข้า:
  นำเข้าจากแดนไกล <ชื่อโมดูล> <ครับ หรือ ค่ะ>

จุดเริ่มโปรแกรม:
  yo เริ่มละนะ|<รายการตัวแปรรับเข้า>| อยู่ในนี้
      <คำสั่ง>*
  เหรอวะ

คำสั่งทั่วไป:
  - ประกาศตัวแปร: <ประเภท> <ชื่อตัวแปร> = <นิพจน์> นะ
  - กำหนดค่าใหม่: <ชื่อตัวแปร> = <นิพจน์> นะ
  - แสดงผล: ตะโกน/<นิพจน์>\ นะ
  - จบการทำงาน: พอละเหนื่อย <นิพจน์> นะ
  - หยุดลูป: พอเหอะ นะ
  - ข้ามรอบลูป: ช่างมันรอบนี้ นะ

คำสั่งควบคุม:
  - เงื่อนไข:
    ถ้า /<เงื่อนไข>\ อยู่ในนี้
        <คำสั่ง>*
    เหรอวะ ช่างแม่ง อยู่ในนี้
        <คำสั่ง>*
    เหรอวะ

  - ลูปแบบ While:
    วนแม่งเข้าไป /<เงื่อนไข>\ อยู่ในนี้
        <คำสั่ง>*
    เหรอวะ

  - ลูปแบบ For Range:
    เอาตั้งแต่ /ตัวเลข <ชื่อตัวแปร> = <ค่าเริ่มต้น> ไปจนถึง <ค่าสิ้นสุด>\ อยู่ในนี้
        <คำสั่ง>*
    เหรอวะ
