## ภาพรวมของภาษา

ภาษา **Araiwa (อะไรวะ)** เป็นภาษาโปรแกรมเชิงคำสั่ง (Imperative) ที่ออกแบบมาเพื่อความบันเทิงและการทดสอบตรรกะแบบมีเอกลักษณ์ ไวยากรณ์ทั้งหมดใช้ภาษาไทยผสมผสานกับสัญลักษณ์ทางคณิตศาสตร์ และมีระบบ Linter/Runtime Traps ที่คอยดักจับพฤติกรรมกวนๆ ของผู้เขียนโปรแกรม เช่น การเว้นวรรคมากเกินไป, การใช้คอมเมนต์แบบภาษาซี, การคำนวณตัวเลขต้องห้าม, หรือการวนลูปหนักเกินจำเป็น

## สถาปัตยกรรมและหลักการทำงาน

ตัว Interpreter ถูกออกแบบตามสถาปัตยกรรมคอมไพเลอร์/อินเทอร์พรีเตอร์มาตรฐาน แบ่งเป็นโมดูลที่แยกหน้าที่ชัดเจน:

```
[ ซอร์สโค้ด .arw ]
        │
        ▼
   [ Lexer / Tokenizer ] (lexer.py, tokens.py)
        │ - สแกนคำสำคัญภาษาไทยและสัญลักษณ์
        │ - ตรวจสอบ Spacebar นับจำนวนช่องว่างก่อน "นะ"
        │ - แยกแยะเครื่องหมาย / (วงเล็บเปิด vs เครื่องหมายหาร)
        │ - ดักจับ Trap "//" และจัดการคอมเมนต์
        ▼
     [ Tokens ]
        │
        ▼
   [ Parser ] (parser.py, ast_nodes.py)
        │ - แปลง Token เป็น Abstract Syntax Tree (AST)
        │ - จัดการลำดับความสำคัญของ Operators (Precedence)
        │ - ตรวจสอบความถูกต้องของโครงสร้างบล็อก (อยู่ในนี้ / เหรอวะ)
        │ - ตรวจสอบหางเสียง "นะ" ปิดท้ายทุกคำสั่ง
        ▼
    [ AST Tree ]
        │
        ▼
 [ Interpreter / Runtime ] (interpreter.py, runtime.py, errors.py)
        │ - ควบคุม Scope ของตัวแปรแบบ Lexical Scoping
        │ - ประมวลผลตรรกะการคำนวณและการต่อสตริง
        │ - บังคับใช้ Type Coercion และ Type Checking
        │ - นับรอบลูปเพื่อดักจับ Fatal Loop Trap (> 6967 รอบ)
        │ - ตรวจสอบตัวเลขต้องห้าม (Alpha Trap: 67, Memory Loss: > 6967)
        ▼
 [ ผลลัพธ์หน้าจอ / stdout, stderr ]
```

## ความสามารถในเวอร์ชันปัจจุบัน (v0.1)

### 1. จุดเริ่มต้นโปรแกรมและ Parameter Pipeline
- มี Entry Point บังคับเพียงจุดเดียวคือ `yo เริ่มละนะ|<รายการตัวแปร>| อยู่ในนี้ ... เหรอวะ`
- รองรับการรับ Arguments จาก Command Line เข้าสู่พารามิเตอร์ของโปรแกรมโดยตรง เช่น `yo เริ่มละนะ|รอบ, ผู้เล่น|`

### 2. ระบบโมดูลและศุลกากรแดนไกล
- รองรับการนำเข้าโมดูลด้วยคำสั่ง `นำเข้าจากแดนไกล <ชื่อโมดูล> <ครับ หรือ ค่ะ>`
- ตรวจสอบความสุภาพของคำลงท้ายอย่างเข้มงวด

### 3. ชนิดข้อมูล (Data Types)
- **`ตัวเลข` (Number):** รองรับทั้ง Integer และ Float
- **`ข้อความ` (String):** เขียนอยู่ในเครื่องหมายคำพูด `"..."` รองรับ Escape Characters (`\n`, `\t`, `\"`, `\\`)
- **`เรื่องโกหก` (Boolean):** มีค่าคงที่สองค่าคือ `จริง` (True) และ `ตอแหล` (False)

### 4. สัญลักษณ์และขอบเขต (Delimiters)
- วงเล็บเปิด `(` แทนด้วย `/`
- วงเล็บปิด `)` แทนด้วย `\`
- ปีกกาเปิด `{` แทนด้วย `อยู่ในนี้`
- ปีกกาปิด `}` แทนด้วย `เหรอวะ`
- เครื่องหมายต่อข้อความแทนด้วย `฿` (Thai Baht symbol)

### 5. การควบคุมทิศทาง (Control Flow)
- **เงื่อนไข:** `ถ้า /<เงื่อนไข>\ อยู่ในนี้ ... เหรอวะ` และ `เหรอวะ ช่างแม่ง อยู่ในนี้ ... เหรอวะ` (Else)
- **While Loop:** `วนแม่งเข้าไป /<เงื่อนไข>\ อยู่ในนี้ ... เหรอวะ`
- **For Range Loop:** `เอาตั้งแต่ /ตัวเลข <ตัวแปร> = <เริ่มต้น> ไปจนถึง <สิ้นสุด>\ อยู่ในนี้ ... เหรอวะ` (Inclusive range ทั้งเดินหน้าและถอยหลัง)
- **การควบคุมลูป:** `พอเหอะ นะ` (Break) และ `ช่างมันรอบนี้ นะ` (Continue)

### 6. การแสดงผล การรับข้อมูลสด (Input) และการคืนค่า
- **รับข้อมูลสดจากคีย์บอร์ด (Interactive Input):** `ถาม/<ข้อความคำถาม>\` หรือ `บอกมา/<ข้อความคำถาม>\` (ทำงานเหมือน `input()` ใน Python หรือ `scanf` ใน C ปรับประเภทข้อมูลและตรวจจับ Alpha Trap ให้อัตโนมัติ)
- **แสดงผลออกหน้าจอ:** `ตะโกน/<นิพจน์>\ นะ`
- **คืนค่าและออกจากโปรแกรม:** `พอละเหนื่อย <นิพจน์> นะ`

## กฎเหล็กและกับดักที่ห้ามฝ่าฝืน (Strict Meme Rules)

| กฎ / กับดัก | เงื่อนไข | พฤติกรรม / ข้อความแจ้งเตือน |
| :--- | :--- | :--- |
| **Spacebar Linter Warning** | เคาะเว้นวรรคก่อนคำว่า `นะ` มากกว่า 10 เคาะ | พ่นคำเตือนออก `stderr` แต่ให้โปรแกรมรันต่อได้:<br>`[คำเตือน]: เว้นวรรคหาพ่อมึงเหรอ เคาะ Spacebar เยอะขนาดนี้แป้นพิมพ์มึงค้างเหรอวะ? (แต่ช่างแม่ง รันต่อให้ก็ได้)` |
| **คำสั่งไม่มีหางเสียง** | ลืมลงท้ายคำสั่งด้วยคำว่า `นะ` | `SyntaxError: คำสั่งไม่มีหางเสียง กรุณาลงท้ายด้วย นะ` |
| **ห้ามใช้คอมเมนต์ภาษาซี** | พบ Token `//` ในโค้ด (นอกข้อความ) | `SyntaxError: ใส่ขีดสองอันมาทำไมวะ จำไม่ได้เหรอว่าต้องพิมพ์ว่า อันนี้ไม่ใช้:` |
| **กฎศุลกากรแดนไกล** | คำสั่ง `นำเข้าจากแดนไกล` ไม่ลงท้ายด้วย `ครับ` หรือ `ค่ะ` | `RuntimeError: ศุลกากรปฏิเสธพัสดุ พูดจาห้วนเกินไป กรุณาลงท้ายด้วย ครับ หรือ ค่ะ ให้เรียบร้อย` |
| **การบวกสตริงข้ามประเภท** | เอา `ข้อความ + ตัวเลข` หรือ `ตัวเลข + ข้อความ` ด้วยเครื่องหมาย `+` | `RuntimeError: ลองไปถามพ่อมึง`<br>*(การนำข้อความมาต่อกับตัวเลขต้องใช้เครื่องหมาย `฿` เท่านั้น)* |
| **Boolean Coercion** | `เรื่องโกหก + ตัวเลข` หรือ `เรื่องโกหก + ข้อความ` | `จริง` = 1, `ตอแหล` = 0 หากบวกกับตัวเลข<br>หากบวกกับข้อความจะแปลงเป็นสตริง `"จริง"` หรือ `"ตอแหล"` อัตโนมัติ |
| **Alpha Trap (เลข 67)** | ค่าคงที่, การกำหนดค่า หรือผลลัพธ์คำนวณเท่ากับ `67` หรือ `67.0` | `RuntimeError: บ่ ไม่ขำ gen alpha หรือไง` |
| **Memory Loss Trap** | ตัวเลขมีค่ามากกว่า `6967` | `RuntimeError: อะไรวะ จำไม่ได้`<br>*(หากต้องการเก็บตัวเลขที่มากกว่านี้ ต้องเก็บเป็น "ข้อความ")* |
| **Loop Trap** | ลูปใดลูปหนึ่งทำงานวนซ้ำเกิน `6967` รอบ | `FatalError: วนเหี้ยไรเกิน 6967 รอบ อะไรวะ จำไม่ได้ เหนื่อยโว้ย!` |

## ไวยากรณ์และโครงสร้างคำสั่ง

### โครงสร้างไฟล์
```araiwa
นำเข้าจากแดนไกล จอแสดงผล ครับ
นำเข้าจากแดนไกล เครื่องคิดเลข ค่ะ

yo เริ่มละนะ|รอบ, ผู้เล่น| อยู่ในนี้
    <คำสั่ง>*
เหรอวะ
```

### การประกาศตัวแปรและการกำหนดค่า
```araiwa
ข้อความ ชื่อ = "สมชาย" นะ
ตัวเลข อายุ = 25 นะ
เรื่องโกหก โสด = จริง นะ

อายุ = 26 นะ
```

### การรับข้อมูลจากคีย์บอร์ด (Interactive Input - scanf / input)
```araiwa
อันนี้ไม่ใช้: รับข้อความ
ข้อความ ชื่อผู้เล่น = ถาม/"บอกชื่อของมึงมา: "\ นะ

อันนี้ไม่ใช้: รับตัวเลข (ระบบจะแปลงค่าและตรวจสอบกฎตัวเลข 67 ให้อัตโนมัติ)
ตัวเลข เลขที่ทาย = ถาม/"ทายตัวเลข (1-100): "\ นะ

อันนี้ไม่ใช้: ใช้คำว่า บอกมา แทนคำว่า ถาม ได้เช่นกัน
ตัวเลข แต้ม = บอกมา/"ใส่แต้ม: "\ นะ
```

### การต่อสตริงด้วย ฿
```araiwa
ข้อความ ข้อมูล = "ชื่อ: " ฿ ชื่อ ฿ " อายุ: " ฿ อายุ นะ
ตะโกน/ข้อมูล\ นะ
```

### เงื่อนไข (If-Else)
```araiwa
ถ้า /อายุ มากกว่าหรือเท่ากับ 18\ อยู่ในนี้
    ตะโกน/"เป็นผู้ใหญ่แล้ว"\ นะ
เหรอวะ ช่างแม่ง อยู่ในนี้
    ตะโกน/"ยังเป็นเด็กอยู่"\ นะ
เหรอวะ
```

### ตัวดำเนินการเปรียบเทียบ
รองรับทั้งสัญลักษณ์สากลและคำภาษาไทย:
- `==` หรือ `เท่ากับ`
- `!=` หรือ `ไม่เท่ากับ`
- `>` หรือ `มากกว่า`
- `<` หรือ `น้อยกว่า`
- `>=` หรือ `มากกว่าหรือเท่ากับ`
- `<=` หรือ `น้อยกว่าหรือเท่ากับ`

### การวนลูป (Loops)
```araiwa
เอาตั้งแต่ /ตัวเลข i = 1 ไปจนถึง 5\ อยู่ในนี้
    ถ้า /i เท่ากับ 2\ อยู่ในนี้
        ช่างมันรอบนี้ นะ    อันนี้ไม่ใช้: ข้ามรอบนี้ (Continue)
    เหรอวะ
    ถ้า /i เท่ากับ 4\ อยู่ในนี้
        พอเหอะ นะ          อันนี้ไม่ใช้: หยุดลูปทันที (Break)
    เหรอวะ
    ตะโกน/"รอบ: " ฿ i\ นะ
เหรอวะ
```

### คอมเมนต์ (Comments)
```araiwa
อันนี้ไม่ใช้: คอมเมนต์บรรทัดเดียว ข้ามข้อความไปจนจบบรรทัด

อันนี้ไม่ใช้="
คอมเมนต์หลายบรรทัด
ข้ามข้อความทั้งหมดระหว่าง =" และ "=
"=
```

## วิธีติดตั้งและใช้งาน (Usage Guide)

### 1. ความต้องการของระบบ
ติดตั้ง **Python 3.8** ขึ้นไปบนเครื่องของคุณ ตรวจสอบด้วยคำสั่ง:
```bash
python --version
```

### 2. การสั่งรันโปรแกรม
สั่งรันไฟล์ภาษา Araiwa (`.arw`) ผ่าน CLI:
```bash
python araiwa.py <ชื่อไฟล์.arw> [argument 1] [argument 2] ...
```

**ตัวอย่าง:**
```bash
python araiwa.py test.arw 1 มหาเทพโปรแกรมเมอร์
```

**ผลลัพธ์:**
```text
[คำเตือน]: เว้นวรรคหาพ่อมึงเหรอ เคาะ Spacebar เยอะขนาดนี้แป้นพิมพ์มึงค้างเหรอวะ? (แต่ช่างแม่ง รันต่อให้ก็ได้)
ยินดีต้อนรับผู้เล่น: มหาเทพโปรแกรมเมอร์
ผ่านเกณฑ์แล้ววะ
รอบปัจจุบัน: 1
รอบปัจจุบัน: 3
สถานะ + แต้ม = 101
```

### 3. การรันชุดทดสอบความถูกต้อง (Test Suite)
สามารถทดสอบกฎและกับดักทั้งหมด 11 รายการผ่านสคริปต์ทดสอบอัตโนมัติ:
```bash
python -X utf8 test_traps.py
```

เมื่อผ่านทั้งหมดจะแสดงข้อความ:
```text
[PASS] // Trap test passed
[PASS] Missing 'นะ' trap test passed
[PASS] Customs trap test passed
[PASS] String + Number trap test passed
[PASS] Number + String trap test passed
[PASS] Number 67 (Alpha Trap) test passed
[PASS] Number > 6967 (Memory Loss Trap) test passed
[PASS] Loop trap (while loop) test passed
[PASS] Loop trap (infinite loop count) test passed
[PASS] Boolean coercion test passed
[PASS] Spacebar warning test passed

ALL 11 TESTS PASSED SUCCESSFULLY!
```

## ตัวอย่างโปรแกรมจริง (Real-World Examples)

### 1. ระบบคิดเงินร้านอาหารตามสั่ง (Restaurant POS System - `pos_cashier.arw`)
โปรแกรมจำลองแคชเชียร์ร้านอาหารที่ใช้งานคำสั่งควบคุมครบถ้วน ทั้งการวนลูปรับออเดอร์, การคำนวณเงินสด, การออกใบเสร็จรับเงิน และการทอนเงินสดอย่างสมบูรณ์:

- **ฟังก์ชันการทำงาน:**
  - วนลูปแสดงเมนูอาหารและรับคำสั่งซื้อแบบ Interactive ผ่านคำสั่ง `ถาม`
  - คำนวณยอดเงินสะสมและจำนวนจานอัตโนมัติ
  - สรุปยอดใบเสร็จรับเงิน
  - ตรวจสอบยอดเงินสดที่ลูกค้าจ่าย (หากเงินไม่พอ ระบบจะแจ้งยอดที่ขาดและให้จ่ายเพิ่ม)
  - คำนวณเงินทอนอย่างถูกต้อง พร้อมตรวจเช็กหลบ Alpha Trap (67)

**คำสั่งรันโปรแกรม:**
```bash
python araiwa.py pos_cashier.arw
```

**ตัวอย่างการทำงาน:**
```text
===============================================
 🍛 ยินดีต้อนรับสู่ระบบคิดเงินร้านอาหารตามสั่ง (POS) 
===============================================

--- เมนูอาหาร ---
1. กะเพราหมูกรอบไข่ดาว (70 บาท)
2. ข้าวผัดหมูโบราณ (50 บาท)
3. ต้มยำกุ้งน้ำข้น (120 บาท)
4. ชาไทยเย็นหวานเจี๊ยบ (30 บาท)
5. 💳 คิดเงิน / ชำระบิล
6. ❌ ยกเลิกและออกจากระบบ
👉 กรุณาเลือกรายการ (1-6): 1
สั่งกี่จานดี: 2
✅ เพิ่ม กะเพราหมูกรอบ 2 จาน (ยอดสะสม: 140 บาท)

--- เมนูอาหาร ---
...
👉 กรุณาเลือกรายการ (1-6): 4
สั่งกี่แก้วดี: 1
✅ เพิ่ม ชาไทยเย็น 1 แก้ว (ยอดสะสม: 170 บาท)

--- เมนูอาหาร ---
...
👉 กรุณาเลือกรายการ (1-6): 5

================ ใบเสร็จรับเงิน ================
รวมจำนวนที่สั่งทั้งหมด: 3 รายการ
ยอดรวมทั้งสิ้น: 170 บาท
-----------------------------------------------
💵 รับเงินสดจากลูกค้า: 100
❌ เงินไม่พอเว้ย! ยังขาดอีก 70 บาท จ่ายเพิ่มมาเดี๋ยวนี้
💵 รับเงินสดจากลูกค้า: 200
💰 เงินทอน: 30 บาท
🎉 ชำระเงินเรียบร้อย ขอบใจที่มาอุดหนุน โอกาสหน้าเชิญใหม่นะไอ้สอง!
===============================================
```

### 2. เกมทายตัวเลข (Interactive Number Guessing Game - `guess_game.arw`)
เกมทายตัวเลขปริศนาแบบ Real-time โดยใช้ลูป `วนแม่งเข้าไป` และฟังก์ชัน `ถาม` เพื่อรับค่าตัวเลขที่ผู้เล่นทายทีละรอบ พร้อมแจ้งใบ้ว่า "มากเกินไป" หรือ "น้อยเกินไป" จนกว่าจะทายถูก:

**คำสั่งรันโปรแกรม:**
```bash
python araiwa.py guess_game.arw
```

## โครงสร้างโค้ดภายในโปรเจกต์

| ไฟล์ | หน้าที่และความรับผิดชอบ |
| :--- | :--- |
| `araiwa.py` | จุดเริ่มต้น CLI สำหรับรับ Argument และประสานงานโมดูลต่างๆ |
| `lexer.py` | ตัววิเคราะห์คำ (Tokenizer) ตัดคำภาษาไทย จัดการ Whitespace และ Trap `//` |
| `tokens.py` | กำหนดประเภท Token (`TokenType`) และคลาสโครงสร้างข้อมูล `Token` |
| `parser.py` | ตัววิเคราะห์ไวยากรณ์ แปลง Token ให้กลายเป็น Abstract Syntax Tree (AST) |
| `ast_nodes.py` | โครงสร้างคลาส Node ต่างๆ ของ AST ทั้ง Expression และ Statement |
| `runtime.py` | จัดการ Scope ตัวแปร, ฟอร์แมตค่า, Type Check และฟังก์ชัน `check_number` |
| `interpreter.py` | ตัวประมวลผลคำสั่ง รันโค้ดจาก AST, จัดการ Loop Counter และ I/O |
| `errors.py` | คลาส Exception เฉพาะของภาษา เพื่อพิมพ์ Error Message ตามสเปกเป๊ะ 100% |
| `test.arw` | ซอร์สโค้ดตัวอย่างชุดทดสอบอย่างเป็นทางการ |
| `guess_game.arw` | เกมทายตัวเลขแบบ Interactive เล่นสดผ่าน Terminal ด้วยคำสั่ง `ถาม` |
| `pos_cashier.arw` | ระบบคิดเงินร้านอาหารตามสั่ง (POS) เต็มรูปแบบแบบ Interactive |
| `test_traps.py` | ชุดทดสอบ Unit Tests อัตโนมัติสำหรับดักจับ Error และ Meme Traps ทุกข้อ |
| `README.md` | เอกสารคู่มือและข้อกำหนดกฎเกณฑ์ทั้งหมดฉบับภาษาไทย |
| `README_EN.md` | เอกสารคู่มือและข้อกำหนดกฎเกณฑ์ทั้งหมดฉบับภาษาอังกฤษ |
